# 판교 CAD 레이어 점검 결과

## 대상 파일

판교 폴더에서 확인된 DWG 파일은 5개다.

| 파일명 | DWG 헤더 |
| --- | --- |
| 090924 별첨2-가.용도지역결정(변경)도.dwg | AC1018 |
| 091120 별첨2-나.토지이용결정(변경)도.dwg | AC1018 |
| 091120 별첨2-다.도시기반시설결정(변경)도.dwg | AC1018 |
| 091120 별첨2-라.가구및획지결정(변경)도.dwg | AC1018 |
| 091120 별첨2-마.건축물및기타사항결정(변경)도.dwg | AC1018 |

`AC1018`은 AutoCAD 2004/2005/2006 계열 DWG 형식이다.

## 현재 환경에서의 열람 가능 여부

현재 작업 환경에서 확인한 도구:

- QGIS 3.36.3 설치됨
- QGIS 포함 GDAL/OGR 3.9.0 설치됨
- `ogrinfo.exe` 사용 가능
- Python `geopandas`, `shapely` 사용 가능
- `osgeo`, `ezdxf` 미설치
- AutoCAD `AcCoreConsole`, DWG TrueView, ODA File Converter 미확인

QGIS GDAL의 CAD 드라이버로 DWG 열람을 시도했으나 실패했다.

오류 메시지:

```text
ERROR 6: libopencad 0.3.4 does not support this version of CAD file.
Supported formats are:
DWG R2000 [ACAD1015]
```

즉, 현재 GDAL/libopencad는 DWG R2000(`AC1015`)만 지원하는데, 대상 파일은 `AC1018`이라 직접 열람할 수 없다.

## 키워드 확인 결과

아래 키워드는 DWG 바이너리에서 단순 문자열 검색도 수행했지만, 압축/인코딩/내부 구조 문제로 직접 검출되지 않았다.

- 지구단위
- 구역경계
- 계획구역
- 자족
- 복합용지
- 업무
- 산업
- 도시지원
- 용도지역

이 결과는 "해당 레이어가 없다"는 의미가 아니다. 현재 파일 형식이 직접 파싱되지 않아 레이어 테이블을 정상적으로 읽지 못했다는 의미다.

## GeoJSON 변환 가능성

변환 자체는 가능하다. 다만 먼저 DWG를 다음 중 하나로 변환해야 한다.

1. DXF R2000 또는 더 낮은 버전
2. ESRI Shapefile
3. GeoPackage

변환 후에는 다음 작업이 가능하다.

- 레이어 전체 목록 추출
- 레이어별 객체 수 집계
- 키워드 포함 레이어 필터링
- 전체 Extent 산출
- 폴리라인/폴리곤 중 외곽 경계 후보 추출
- EPSG:5186 또는 추정 좌표계 지정 후 EPSG:4326 GeoJSON 변환

현재 판교 지구경계 SHP가 EPSG:5186이었고 CAD 도면도 국내 도시계획 도면이므로, 변환된 CAD 좌표값이 200,000 / 530,000 부근이면 EPSG:5186 또는 인접 한국 중부원점 계열 좌표계일 가능성이 높다. 다만 DWG 자체에서 좌표계를 읽지 못했으므로 확정은 변환 후 좌표 범위 대조가 필요하다.

## 다음 실행 절차

DWG를 DXF R2000으로 변환한 파일을 제공하거나, ODA File Converter/AutoCAD/TrueView가 설치되면 아래 절차로 처리한다.

1. DWG를 DXF R2000으로 일괄 변환
2. QGIS GDAL `ogrinfo` 또는 Python `ezdxf`로 레이어 목록 추출
3. 레이어별 객체 수 집계
4. 키워드 포함 레이어 필터링
5. 전체 Extent 산출
6. 닫힌 LWPOLYLINE/POLYLINE 또는 큰 면적 POLYGON을 외곽 경계 후보로 선별
7. 좌표계를 EPSG:5186으로 가정 또는 검증
8. `GeoJSON`으로 저장
